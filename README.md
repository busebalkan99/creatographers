# Creatographers

Fotoğraf kulübü oylama uygulaması, tasarım prototipi.

**Canlı:** https://busebalkan99.github.io/creatographers/

Telefonda açın. Alttaki hattı sürükleyerek puan verin, yukarı kaydırınca sıradaki kare gelir.

Bu bir tasarım prototipi: puanlar kaydedilmez, sayfa yenilenince sıfırlanır.
Fotoğraflar picsum.photos'tan gelen rastgele görsellerdir.
